# Encounter Receipt System + Protocol Demo Stabilization

## Objective
Make Presence Protocol demonstrable through observable encounter receipts.

## Current Truth
The current MVP verifies signed BLE device-to-device proximity events, not human identity.

## Milestone Goal
Expose a clear receipt-style proof surface showing:
- encounter timestamp
- peer/device reference
- signature validity
- protocol stage
- reward/CPOP record where available
- local receipt persistence evidence

## Demo Principle
Only show claims that are implemented or observable.
